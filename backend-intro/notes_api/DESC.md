# Серверное API для заметок

Реализуем с тобой простенькое API на Flask для заметок (списков дел).

## Структура заметки

Заметка содержит такие поля:

```json
{
    "id": 0,  // уникальный id, по которому их находим и получаем доступ - инкрементрировать придется вручную, с БД поработаем позже
    "text": "Содержимое заметки",  
    "done": true  // для списков дел - отмечаем выполненные/невыполненные
}
```

## Эндпоинты

Эндпоинты - это по сути существующие/необходимые запросы к API. В общем их описание выглядит так:

`GET /`
- получить ответ о том, что сервис запущен и работает

`GET /notes`
- получить json со всеми заметками/пунктами

`GET /notes/<int:note_id>`
- получить конкретную заметку/пункт списка по `id`

`POST /notes {"text":"note text"}`
- создать заметку: в тело запроса должен передаваться json с текстом заметки, создается undone

__Добавить эндпоинты__

`PATCH /notes/<int:note_id>`
- отметить заметку выполненной ({"done": true} в json)

`DELETE /notes/<int:note_id>`
- удалить заметку (notes.pop(index), саму заметку ищем по id)
