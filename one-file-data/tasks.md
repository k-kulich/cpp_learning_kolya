# Задачи - подготовительные к алго


## Связные списки

Начнем с односвязного. Это структура данных, в которой каждый элемент (все элементы одного типа) знает только о следующем за собой. То есть мы можем добавить любое количество элементов, но доступ получаем только по порядку.

![](односвязные-списки.svg)

Тебе нужно реализовать односвязный список с помощью pointer-ов, на стуктурах/классах, который поддерживает следующие операции:

- `add` - добавить элемент (в конец)
- `remove` - удалить элемент (произвольный, по индексу)
- `find` - найти и вернуть индекс элемента по значению
- `insert` - вставить в определенное место элемент
- `size` - вернуть количество элементов в списке

Ну и, разумеется, операции доступа по индексу (без изменения списка) и прочие базовые, если решишь писать на классе.

Задачи, для которых это может понадобится:

- [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/description/)
- [Reorder List](https://leetcode.com/problems/reorder-list/description/)


## Авторские задачи

Частичная специализация шаблона для указателей

Цель: отработка частичной специализации классов.

Задание:
- Напишите шаблон класса IsPointer<T>, который содержит статическую константу value типа bool, равную true, если T является указателем, и false в противном случае.
- Реализуйте это через частичную специализацию для T*.

Дополнительно:
- Создайте шаблонную переменную is_pointer_v = IsPointer<T>::value для удобства.

Проверка:
- Статически проверьте (через static_assert), что is_pointer_v<int> == false, а is_pointer_v<int*> == true.
